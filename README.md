## 📖 Visão Geral

**Neon Slither** é um jogo viciante e dinâmico que combina mecânicas simples com decisões estratégicas intensas. O jogador controla uma cobra em uma arena repleta de partículas luminosas, crescendo gradualmente ao coletá-las e derrotar adversários controlados por inteligência artificial.

O jogo foi desenvolvido em modo **singleplayer contra bots**, proporcionando uma experiência acessível, rápida e desafiadora, ideal tanto para partidas casuais quanto para jogadores que buscam dominar a arena.

---

## 🕹️ Mecânicas do Jogo

- Controle suave e responsivo
- Crescimento progressivo da cobra
- Bots com comportamento estratégico
- Sistema de eliminação por colisão
- Arena dinâmica com partículas luminosas
- Estilo visual neon moderno

> ⚠️ Um único erro pode ser fatal: qualquer colisão encerra a partida.

## 🚀 Executando o Projeto Localmente

### ✅ Pré-requisitos
- Node.js (versão recomendada LTS)

### ▶️ Passo a passo

1. Instale as dependências:
   ```bash
   npm install

2. Configure o ambiente
Crie o arquivo .env.local e defina:

GEMINI_API_KEY=your_api_key_here


3. Inicie o servidor de desenvolvimento:

npm run dev


4. Acesse no navegador:

http://localhost:3000
